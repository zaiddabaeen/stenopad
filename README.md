# Steno Pad

The web pages of Steno Pad, a voice recorder for iPhone, iPad and Mac that transcribes on the
device. Nothing is uploaded and there is no account.

Published with GitHub Pages at https://zaiddabaeen.github.io/stenopad/

- `privacy-policy.html`: the privacy policy the App Store listing and the app link to.
- `support.html`: answers to common questions, and where to write: support@z-proj.com.

The pages are plain HTML with no scripts, no trackers and nothing loaded from elsewhere. A push
to `main` publishes them.
